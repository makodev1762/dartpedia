# Proyecto Guiado Dartpedia 🚀

¡Bienvenido al repositorio oficial de mi aprendizaje y práctica con **Dart**! Este proyecto forma parte del recorrido guiado de **Dart.dev Learning**, diseñado para aprender a dominar el lenguaje desde cero hasta bases sólidas.

---

## 📖 ¿De qué trata este proyecto?

**Dartpedia** es una aplicación/práctica guiada basada en los fundamentos oficiales de la documentación de [Dart](https://dart.dev/). El objetivo principal es explorar y aplicar los conceptos esenciales del lenguaje de programación Dart en un entorno práctico, limpio y estructurado.

---

## 🛠️ ¿Qué es lo que se vio / Temas cubiertos?

A lo largo de este proyecto guiado, se abordaron y pusieron en práctica los siguientes conceptos clave:

*   **Sintaxis básica y tipos de datos:** Variables (`var`, `final`, `const`), tipos numéricos, cadenas de texto (`String`), booleanos y colecciones (`List`, `Map`, `Set`).
*   **Control de flujo:** Estructuras condicionales (`if`, `else`, `switch`) y bucles (`for`, `while`, `do-while`).
*   **Funciones y Programación Orientada a Objetos (POO):** 
    *   Creación y uso de funciones (parámetros posicionales, nombrados y opcionales).
    *   Definición de clases, constructores (incluyendo constructores con nombre y `const`), getters y setters.
    *   Herencia, interfaces, clases abstractas y mixins.
*   **Programación Asíncrona:** Manejo de `Future`, `async/await` y `Stream` para operaciones asíncronas en Dart.
*   **Manejo de errores:** Uso de bloques `try`, `on`, `catch` y `finally`.

## 🚀 Cómo empezar a usarlo

Si deseas clonar este repositorio y explorar el código fuente, sigue estos pasos:

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/dartpedia.git
   ```

2. **Accede al directorio del proyecto:**
   ```bash
   cd dartpedia
   ```

3. **Ejecuta los archivos de Dart:**
   Puedes correr cualquiera de los scripts principales utilizando el SDK de Dart desde tu terminal:
   ```bash
   dart run bin/main.dart
   ```
   *(Asegúrate de reemplazar `bin/main.dart` por la ruta del archivo que desees ejecutar).*
